## 1. 개요

### 1.1 목적
미루기 성향을 극복하고, **매일 5분 마이크로 해빗 실천**과 **만화 주인공 히어로 육성(Tier/Rank/조각)** 시스템을 통해 습관을 형성한다.

### 1.2 범위 (In / Out)
| In Scope | Out Scope |
|---|---|
| **100% 로컬 DB (Room) 기반 운영** | 서버/클라우드 동기화 |
| 단일 사용자 (로컬 프로필) | 다중 계정/로그인 |
| 습관 CRUD, 타이머, 체크인, 육성 | 소셜/커뮤니티 기능 |
| **로컬 기반 랭킹 (가상 NPC 비교)** | 서버 실시간 랭킹 |
| 로컬 백업/복원 (JSON) | 푸시 알림 (v1 범위 외) |
| 국문/영문 (i18n 대비) | 기타 언어 (v2+) |

### 1.3 용어 정의
- **조각 (Fragment)**: 습관 완료 시 획득하는 **레벨업 재화**. 일일 최대 10개.
- **Tier (계급)**: B → A → S → 신화 로 진화하는 상위 단계.
- **Rank (랭크)**: Tier 내 진행도 (0~100). **조각 누적과 1:1 대응**.
- **스트릭 (Streak)**: 하루 1개 이상 습관 실천 시 +1 되는 연속 달성일.

> **폐지 안내 (Task 21)**: XP(경험치) 시스템은 완전히 폐지되었습니다. 모든 보상은 조각으로 통일됩니다.

### 1.4 히어로 정의
| 히어로 | 성별 | 특성 | 패시브 |
|---|---|---|---|
| **Rookie Rune (루키)** | 남 | Passionate Achiever | 표시용 (게임플레이 개입 없음) |
| **Spark Aria (아리아)** | 여 | Positive Motivator | 표시용 (게임플레이 개입 없음) |

> **Task 21**: 히어로 패시브는 게임플레이에 영향을 주지 않습니다. 히어로 선택은 UI/서사 요소로만 유지됩니다.

### ACT-01: "지금 5분만 하기" (즉석 습관 + 타이머)
- FAB 클릭 → 습관 입력 다이얼로그 (이름)
- 시작 → 5분 타이머 실행 (메모리만)
- 5분 완주 + 완료 클릭 → DB 등록 + 체크 + 조각 +1 → 축하 화면 1.5초 → 메인
- 포기/뒤로가기 → 아무것도 저장 안 됨
- 5분 미달 완료 버튼 비활성화
